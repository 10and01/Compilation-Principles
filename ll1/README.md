# 算术表达式 LL(1) 预测分析程序

## 1. 实现目标

本程序用于对包含 `+`、`-`、`*`、`/`、`(`、`)` 的算术表达式进行 LL(1) 预测分析，并在表达式正确时计算结果。

程序按“每行一个表达式、以分号结束”的方式读取输入文件，把结果写入输出文件，同时在控制台打印同样的报告。

## 2. 文法改写

原始文法：

```text
E -> E + T | T
T -> T * F | F
F -> (E) | i
```

改写后的 LL(1) 文法：

```text
E  -> T E'
E' -> + T E' | - T E' | ε
T  -> F T'
T' -> * F T' | / F T' | ε
F  -> ( E ) | num | id
```

说明：

1. `num` 表示整数常量。
2. `id` 表示标识符。为了让示例中的 `i` 也能参与计算，程序默认把所有标识符按 `1` 处理。
3. 这样改写后，文法消除了左递归，并可直接构造预测分析表。

## 3. 预测分析表

| 非终结符 | `num` | `id` | `(` | `+` | `-` | `*` | `/` | `)` | `$` |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `E`  | `E -> T E'` | `E -> T E'` | `E -> T E'` |  |  |  |  |  |  |
| `E'` |  |  |  | `E' -> + T E'` | `E' -> - T E'` |  |  | `E' -> ε` | `E' -> ε` |
| `T`  | `T -> F T'` | `T -> F T'` | `T -> F T'` |  |  |  |  |  |  |
| `T'` |  |  |  | `T' -> ε` | `T' -> ε` | `T' -> * F T'` | `T' -> / F T'` | `T' -> ε` | `T' -> ε` |
| `F`  | `F -> num` | `F -> id` | `F -> ( E )` |  |  |  |  |  |  |

## 4. 输入与输出

- 输入文件默认是 `input.txt`
- 输出文件默认是 `output.txt`
- 每行一个表达式，表达式以分号 `;` 结束
- 语法树与分析过程图片默认输出到 `images/` 目录（SVG 格式）

运行命令：

```bash
python main.py
```

也可以指定输入输出文件：

```bash
python main.py -i input.txt -o output.txt
```

带图片导出参数：

```bash
python main.py -i input.txt -o output.txt --img-dir images --max-visual-steps 80
```

## 5. 输出内容

程序会输出：

1. 每个表达式的语法判断结果
2. 预测分析过程（符号栈、剩余输入、动作）
3. 语法树
4. 计算过程
5. 错误表达式的详细错误提示
6. 每个表达式对应的语法树图片和分析过程图片路径

## 6. 示例

`input.txt` 中已经提供了几组测试样例，包括：

1. 正确表达式
2. 缺少右括号的错误表达式
3. 操作符位置错误的表达式

运行后会在 `output.txt` 中得到完整报告。

## 7. 代码结构优化

为了便于维护与扩展，代码已按职责拆分：

1. `main.py`：程序入口与参数调度
2. `ll1_core.py`：词法分析、LL(1) 预测分析、求值、文本报告
3. `svg_exporter.py`：语法树和分析过程的 SVG 图片生成

## 8. 图片可视化

程序运行后会自动在图片目录中生成文件：

1. `expression_01_tree.svg`：表达式 1 的语法树
2. `expression_01_process.svg`：表达式 1 的分析过程
3. 其余表达式按同样命名规则生成
